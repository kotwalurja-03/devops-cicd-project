Project Overview

Learning essential DevOps practices through a real project.

⌘

Version Control

Use Git to track code changes and GitHub to store and manage the project repository.

✓

Automated Validation

Run a Python validation script through GitHub Actions to check required website files before deployment.

↗

Continuous Deployment

Automatically publish website changes to GitHub Pages after the validation job succeeds.

CI/CD Pipeline

Four stages take your changes from your computer to the web.

STEP 01

Write Code

Create or update HTML, CSS, JavaScript, and Python files.

STEP 02

Push Changes

Commit your changes and push them to the GitHub repository.

STEP 03

Validate

GitHub Actions runs the automated Python validation script.

STEP 04

Deploy

Publish the website when validation succeeds on the main branch.
